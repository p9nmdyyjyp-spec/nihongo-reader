日语阅读手帐 v0.6 — iPhone GitHub Pages 升级说明

1. 首先在旧版 App 设置页面导出完整备份 JSON，并保存到 iCloud Drive/文件。
2. 解压 v0.6 ZIP；仓库根目录替换 index.html、sw.js、manifest.webmanifest、icon.png。请勿上传 ZIP 本身。
3. GitHub Pages 发布成功后，在 Safari 刷新；若旧版缓存仍存在，稍后重开或以无痕窗口核对部署版本。不要为了刷新而删除网站数据。
4. 新版支持在编辑文章页面复制 ChatGPT 文字，格式为三段：
【标题】
文章标题
【正文】
日语正文
【题目】
問1……和选项……
5. 在文章阅读页添加多条学习笔记、设为重点；底部「复习」汇集重点笔记。无需 API Key。
6. 兼容原有 IndexedDB 文章记录；重新保存文章保留已有笔记；JSON 完整备份包括笔记。
注意：不同浏览器、主屏幕网页 App 可能是不同存储容器；不要清理原位置数据，升级前务必备份。
