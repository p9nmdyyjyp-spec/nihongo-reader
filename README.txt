日语阅读手帐 v0.2

此版本将 N1-N5 等级筛选换成可扩展的“试卷”分类。
在文章库点击“＋ 试卷”添加试卷；添加/编辑文章时可以选择试卷，也可以现场新建。
已有文章及图片继续保存在原 IndexedDB（nihongo-reader-01）中，升级不会清空。历史文章若没有试卷字段会显示“未归档”，可编辑后选择。

上传方法：将 index.html、sw.js、manifest.webmanifest、icon.png 四个文件上传到 GitHub 仓库根目录，覆盖同名旧文件。无需上传压缩包或 README。
更新后建议彻底关闭网页 App 再打开，确保新缓存生效。
升级前请先在旧版“设置”导出备份。
